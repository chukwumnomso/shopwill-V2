# E-Commerce Storefront

A full-featured e-commerce web app built with React, Tailwind CSS and Supabase.

## Features
- User authentication (login & signup)
- Product listings with real data
- Shopping cart
- Responsive design

## Built With
- React
- Tailwind CSS
- Supabase
- JavaScript
